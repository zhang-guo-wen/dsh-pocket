# DSH Pocket

[English](<README.en.md>)

## 背景

**手机扫码就能用电脑上的 DSH。**

下班路上想看看 agent 跑到哪了，出门在外想让电脑上的 agent 干活——这个插件在设置页给你一个「手机访问」入口：局域网扫码，或一键开公网隧道，手机打开就是电脑上的同一个界面，实时同步。

## 截图

**手机上的界面就是电脑上的界面**，流式输出实时同步。

![手机上的 DSH 界面](<docs/interface.jpg>)

## 安装

```sh
npx @deepseek-ai/dsh plugin --profile web add @guowenzhang/dsh-pocket
```

重启 `dsh web`，打开 **设置 → 手机访问**。公网链接默认带 8 位随机密码，别把二维码转给别人。

## 特点

1. **局域网扫码**：同一 WiFi 扫设置页的二维码即开，自动识别本机 IP（WSL 取 Windows 物理网卡）。
2. **公网隧道**：点「开启公网访问」拉起 cloudflared 隧道，人在外面 4G 也能用；可选命名隧道固定域名。
3. **密码可控**：公网与局域网密码都能改成自己固定的 8–64 位；手机登录一次后长期免输。
4. **实时同步**：WebSocket 全透传，电脑上在输出、手机同步在滚，断线自动重连。
5. **手机适配**：窄屏自动变抽屉布局、会话全宽、状态栏安全区、触控优化。
6. **零依赖**：一个 npm 包、一个设置页，无需账号，也无需自己的服务器。

注：口袋里的所有流量都经由你自己的电脑；公网模式请自行确认隧道与密码的暴露范围。
